# Project Instructions & Rules

## 1. Wajib Mobile-Responsive (Prioritas Layar HP)
- Setiap implementasi UI, komponen baru, form, tabel, modal, dan perbaikan tampilan **HARUS selalu responsif dan optimal di layar HP/smartphone** (`max-width: 480px`, `768px`, dsb).
- Pastikan tidak ada horizontal scroll yang rusak, touch target cukup besar, navigasi mobile nyaman, font terbaca jelas, dan layout fleksibel.
