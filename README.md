# SYNERGYMED™ - Advance Solutions For Healthcare

Official web platform & solutions catalog for **PT Sinergi Medika Utama (SynergyMed)**, a leading healthcare technology & medical device provider headquartered in Jakarta, Indonesia.

---

## 🌟 Key Features

- **9 Specialized Business Divisions**:
  - Radiation Oncology
  - Ortho & Neuro
  - Med Supplies
  - Medical Imaging
  - Endosurgery
  - Pain & Rehab
  - Critical Care
  - Ultrasound
  - Enviro & CSSD
- **Dynamic Interactive Catalog**:
  - Instant category filter tabs
  - Real-time search query matching
  - Technical specification modal overlays
  - Direct WhatsApp RFQ / procurement consultation integration
- **Executive Design System**:
  - Polished modern layout with glassmorphic navbar
  - Fully responsive on mobile, tablet, and widescreen displays
- **Zero-Dependency Local Server**:
  - Built-in HTTP server using native Node.js (`server.js`)
  - Fast static serving with automatic browser launch

---

## 🚀 Running Locally

```bash
# Start local development server (Node.js)
npm start

# Or directly run server script
node server.js
```
Open `http://localhost:8080` in your browser.
